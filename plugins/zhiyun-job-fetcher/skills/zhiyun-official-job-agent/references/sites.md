# 分站点专属采集指引（落地版）

> 原始提示词与落地实现的对照。差异均来自 2026-11 实测，逐条标注原因。

## 1. 国家大学生就业服务平台（www.ncss.cn · 教育部）

- **原始提示词**：爬取全量应届生岗位，提取薪资、地点、投递入口。
- **落地**：`server/src/fetcher/ncss.js` —— 仅可见性探测 + 对接指引。
- **差异原因**：实测岗位数据位于学生登录态之后，未登录可见 0 条。本Agent不登录、不破解、不绕过；合规路径是通过学校就业指导中心申请平台「标准化职位接口」机构级对接，采集器只做可见性探测。
- **操作**：`node src/fetcher/run.js --site=ncss`；报告中如实转述探测结论（登录墙 / 网络不可达）。

## 2. 中国公共招聘网（job.mohrss.gov.cn · 人社部）

- **原始提示词**：抓取体制内、规上企业岗位，同步招聘会信息。
- **落地**：`server/src/fetcher/mohrss.js` —— 完整采集。
- **实现要点**：
  - 列表页为 http + SSR，含人社部标准字段码的内嵌 JSON（岗位ID acb200 等）
  - 详情页为静态 HTML：`/cjobs/htmls/cb21gwPages/{id}.html`
  - **联系人姓名/电话字段（aae004/aae005/aae006）一律剔除不存储**（聚合复制他人联系方式有个人信息保护风险），投递引导至岗位原文页
  - 岗位ID规则 `mohrss_{acb200}`，库内已存在直接跳过（增量去重）
- 事业单位/招聘会栏目可后续按同一适配器模式扩展。

## 3. 湖北民办高校就业联盟（*.91wllm.cn · 才立方系统）

- **原始提示词**：定向采集校招专属岗位，优先标注无经验门槛岗。
- **落地**：`server/src/fetcher/wllm.js` + `server/data/university-sites.json`（武汉晴川学院优先）。
- **实现要点**：
  - 七校同一系统，一个适配器全覆盖：武汉晴川学院（优先）、武汉东湖学院、武昌首义学院、文华学院、武昌工学院、汉口学院、武汉工商学院
  - 首页与详情页关键字段为 SSR；列表分页与岗位正文为 AJAX 加载，采集器不依赖（用结构化字段生成摘要）
  - 岗位库全省共享，以岗位ID跨校去重（`wllm_{id}`）
  - 「无经验门槛岗优先标注」：学历"不限"岗位在 APP 内可筛，优先展示由每日推荐承担（`server/src/services/dailyDigest.js`）
- 站点清单配置在 `server/data/university-sites.json`，新增联盟校只需加配置，不改代码。
