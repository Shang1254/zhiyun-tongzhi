# 知云同职 · 使用与部署说明

「知云同职」——民办生公益求职助手。永久免费、无广告、无付费入口；
用户数据本地加密存储，绝不上传任何敏感求职信息。

> **v1.5 起支持公网/海外上线**：静态站导出、PWA 离线、Docker 与 Render/Fly 配置详见
> [上线部署指南.md](上线部署指南.md)。

---

## 一、快速启动（本机运行）

### 1. 启动数据服务（轻后端）

要求：Node.js 18+（开发机为 v22.19.0）

```bash
cd server
npm install
npm start
```

看到 `知云同职 服务已启动: http://localhost:3000` 即成功。
浏览器打开 http://localhost:3000 即可使用全部功能。

首次启动自动完成：
- 导入内置演示岗位库（40 条，其中 6 条虚假岗样本自动标记过滤）
- 生成当日「今日推荐」
- 启动定时任务（03:00 岗位复检 / 09:00 每日推荐）

### 2. 安装安卓 APP

APK 产物：`android/app/build/outputs/apk/debug/app-debug.apk`（约 3.3MB）

**方式 A · 传到手机直接安装**
把 APK 发到安卓手机（微信文件传输/QQ/数据线均可），点击安装，
系统提示「未知来源应用」时允许即可。debug 签名仅供自用与测试。

**方式 B · 自己重新构建**

```bash
cd android
# 1) 修改 gradle.properties 里的 org.gradle.java.home 为你的 JDK 17 路径
# 2) 修改 local.properties 里的 sdk.dir 为你的 Android SDK 路径
gradle assembleDebug        # 或在 Android Studio 中打开 android/ 目录直接 Run
```

**APP 与服务的关系**

- APP 前端完整打包在 APK 内（`assets/www/`），**离线也能用**：
  岗位库（内置数据）、简历生成、PDF 导出全部离线可用。
- 连接服务后可获得：每日更新的岗位库、按画像的「今日推荐」。
  在 APP「个人中心 → 服务连接」填电脑局域网地址（如 `http://192.168.1.100:3000`）
  并点「测试连接」。手机与电脑需在同一 Wi-Fi。

## 二、每日自动更新机制

| 时间 | 任务 | 说明 |
| --- | --- | --- |
| 03:00 | 岗位库复检 | 全量重新评分虚假岗；发布超 30 天标记「可能已过期」 |
| 09:00 | 每日推荐 | 为每个画像生成 3 条带理由的优质岗位 |

- 手动触发（本机）：`curl -X POST "http://localhost:3000/api/admin/run-now?task=all"`
- 保持服务常驻即自动运行；电脑关机则 APP 自动用内置数据离线运行，不报错。
- 如需真正的"凌晨无人值守"，可用 ZCode 定时任务代跑（见第四节）。

## 三、官方岗位采集（已内置，合规渠道）

项目内置官方岗位采集 Agent（详细说明见 [官方岗位采集Agent提示词.md](官方岗位采集Agent提示词.md)）：

```bash
cd server
node src/fetcher/run.js                # 全部站点（限速礼貌采集，约1-3分钟）
node src/fetcher/run.js --site=wllm    # 仅高校联盟（武汉晴川学院优先，7校配置即用）
node src/fetcher/run.js --site=mohrss  # 仅中国公共招聘网（人社部）
node src/fetcher/run.js --limit=5      # 小规模试跑
```

- **每日 0 点自动运行**（node-cron），报告落盘 `server/data/reports/`，日志在 `server/data/logs/`（本地留存不上传）
- 合规机制：可识别 UA、请求间隔 ≥3 秒、运行时 robots.txt 检查、失败重试 3 次指数退避、403/429 熔断
- 采集岗位自动过虚假岗评分引擎，入库后带「✔官方渠道」标签与**原文投递链接**
- 国家大学生就业服务平台（ncss）岗位数据在登录态后，采集器只做探测并给出机构接口对接指引，**不做任何绕过**
- 高校站点清单：`server/data/university-sites.json`，把 `"enabled"` 改为 `true` 即可启用其他六校（同一系统零适配成本）

## 三·补、手动导入（其他合规数据）

**不爬取招聘平台。** 爬取 BOSS 直聘/智联等平台违反其用户协议且有法律风险。

合规接入方式：

1. **导入接口**（推荐）：`POST /api/jobs/import`

```bash
curl -X POST http://localhost:3000/api/jobs/import \
  -H "Content-Type: application/json" \
  -d '{"json":[{"title":"行政专员","company":"某某有限公司","city":"武汉",
       "category":"行政","salaryMin":4000,"salaryMax":5500,
       "salaryType":"monthly","education":"大专",
       "description":"……","postedAt":"2026-11-08"}]}'
```

   也支持 CSV（表头：title,company,city,category,salary_min,salary_max,salary_type,education,description,posted_at）。
   **所有导入岗位自动过虚假岗评分引擎**，命中规则即被标记过滤。

2. **合规数据源建议**：国家统计局/人社部门公开就业信息、企业官网校招页人工整理、
   学校就业指导中心发布的合作岗位。整理为 CSV 后批量导入。

## 四、（可选）让 ZCode 每天代跑更新

在 ZCode 会话中对助手说：

> 每天早上 9 点，进入 `server` 目录运行 `node -e "require('./src/cron').runNow('all')"`
> 并把今日推荐摘要发给我。

即可创建一个本地定时自动化，无需服务器公网部署。

## 五、隐私设计说明（如实陈述）

- 简历与画像：设备本地 AES-GCM-256 加密（PBKDF2-SHA256 25 万次迭代）；
  WebView 离线场景回退 CryptoJS AES。
- 服务端只保存匿名匹配三元组：`deviceId`（随机）+ 求职方向 + 城市 + 学历。
- 「导出我的数据」输出明文 JSON 备份，请用户自行妥善保管。
- 「清空本地数据」一键抹除设备上的全部个人数据。

## 六、诚实的能力边界

| 能力 | 现状 |
| --- | --- |
| 岗位数据 | 内置 40 条虚构演示数据（含 6 条骗术样本），公司名均为虚构 |
| 投递跳转 | 演示数据无真实投递链接；接入真实数据源并附 `applyUrl` 后点击直达 |
| 每日推送 | 应用内「今日推荐」消息中心；厂商级推送通知需开发者资质，公益版未做 |
| 简历生成 | 规则模板（非 AI 生成），零 API 成本，突出实践项目经历 |
| 小程序版 | 未实现；微信「招聘类目」审核需要人力资源服务许可证，与公益免费定位冲突 |
